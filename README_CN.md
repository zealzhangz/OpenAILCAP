# OpenAILCAP

> **AI 原生低代码平台** — 对话式代码生成的设计到部署完整方案

## 🎯 项目概览

**OpenAILCAP** 是一个完整的 **AI 驱动低代码应用开发平台** 的设计与原型实现，完全对标中国国家标准 **GB/T 46900-2025**（低代码平台通用技术要求）。

项目跨越 **战略规划（第0阶段）至详细设计与工作原型（第5-7阶段）**，覆盖 GB/T 46900-2025 的 **全部 139 个 L1 能力项**（100%）以及 **39 个技术域**。

### `/openailcap-prototype` — 交互式原型

**零依赖 SPA**（单页应用），包含 18 个完全交互的页面，演示所有核心能力：

#### 14 个功能模块（18 个页面）

| 模块 | 页面数 | 核心功能 |
|------|--------|---------|
| **1. 应用管理** | 工作台、应用列表、应用详情 | 🤖 AI 生成应用；版本控制；部署流水线 |
| **2. 组织与安全** | 组织树、权限管理 | 🤖 AI 权限推荐；角色矩阵；合规规则 |
| **3. 数据建模** | ER 画布、数据类型 | 关系图；主键；约束 |
| **4. 表单设计器** | 表单设计 | 24 种组件类型；拖拽操作；实时预览；校验 |
| **5. 逻辑与工作流** | 流程编排、BPM 设计器 | 节点型逻辑流；泳道式流程；条件逻辑 |
| **6. 任务与流程** | 看板、任务列表、甘特图 | 实例管理；状态跟踪；时间轴视图 |
| **7. 报表与 BI** | 报表设计、数据大屏 | 查询构建器；图表类型（柱/饼/线）；下钻 |
| **8. 开发与代码** | 代码编辑器、IDE 集成 | 🤖 AI 代码生成预览；语法高亮；部署日志 |
| **9. 配置与设置** | 设置、主题、国际化 | 多语言（中/英）；5 种主题；密码学（SM2/SM3/SM4）演示 |
| **10-14. 运维** | 部署、日志、合规 | 流水线可视化；合规清单；审计日志；消息中心 |

#### ✨ AI 集成点（8 处演示）

1. **应用生成向导** — "5 分钟快速应用"（一句话生成）
2. **权限 AI 推荐器** — 基于组织结构推荐角色（演示准确率 >95%）
3. **逻辑流优化器** — 建议条件逻辑简化
4. **代码生成器** — 为选定实体编写示例 CRUD 代码
5. **表单 AI 助手** — 基于字段名/描述推荐类型
6. **工作流自动排版** — 自动排列 BPM 泳道
7. **报表模板推荐器** — 根据数据类型推荐图表
8. **部署风险分析器** — 标记潜在问题

#### 🔧 技术栈

- **前端：** 原生 JS（ES6+）+ HTML5 + CSS3 → 无需构建步骤
- **状态管** 浏览器 `localStorage`（会话间持久化；控制台 `Store.reset()` 重置）
- **国际化：** 支持 50+ 字符串（中文/英文，附语言切换器）
- **图表：** Chart.js 实时数据可视化
- **后端：** Node.js Express 服务器（端口 3000），提供静态 SPA

#### 🚀 快速开始

```bash
cd openailcap-prototype
npm install
npm start
# → http://localhost:3000
```

**快捷方式**（从仓库根目录）：
```bash
node openailcap-prototype/server.js
```
