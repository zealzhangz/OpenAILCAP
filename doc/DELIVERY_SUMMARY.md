## 🛠️ 技术架构

### 完整技术栈

**前端：**
- React 18 + TypeScript + Vite
- Ant Design 组件库
- Redux Toolkit 状态管理
- React Hook Form 表单
- React Flow (编辑器)
- Monaco Editor (代码编辑)
- i18next (多语言)

**后端：**
- Node.js 18 LTS
- NestJS 10
- Prisma ORM
- PostgreSQL 15
- Redis 7
- TongSuo/GmSSL (国密)

**DevOps：**
- Docker + Docker Compose
- GitHub Actions (CI/CD)
- Kubernetes (后续)
- Loki + Grafana (监控)

### 部署拓扑

```
用户浏览器
  ↓ HTTPS
CDN / WAF
  ↓ HTTPS
Reverse Proxy (Nginx)
  ├─ 前端应用 (React)
  └─ 后端 API (NestJS)
     ├─ PostgreSQL (数据库)
     └─ Redis (缓存/队列)
```
