### 核心创新（3 分钟理解）
- 🤖 **AI 驱动**：一句话快速生成系统（vs 拖拽）
- 🔄 **完整 BPM**：BPMN 2.0 标准 + Temporal 分布式工作流
- 🔐 **企业级安全**：多租户隔离、字段级权限、审计不可篡改
- 👥 **多层级支持**：非技术人员 / 业务分析师 / 开发者

### 技术选型（2 分钟理解）
- **前端**：React 18 + TypeScript + Ant Design Pro
- **后端**：Node.js Express + TypeScript
- **数据库**：PostgreSQL + Redis
- **流程引擎**：Temporal（企业级）
- **AI 模型**：混合（Llama 7B 本地 + GPT-4 云）
- **部署**：Docker + docker-compose（MVP）

### MVP 范围（2 分钟理解）
- **6 个 P0 功能**：应用管理、表单设计、表单 CRUD、权限、日志、部署
- **实现时间**：4 周
- **验收标准**：能用 AI 一句话生成一个可用系统
- **目标用户**：中小企业 IT（1-2 人团队）

## 📞 技术支持

### 常见问题

**Q：为什么选择 Node.js 而不是 Java？**  
A：开发速度快 50%、前后端统一语言、现代工具链成熟。Java 适合大型企业，我们优先追求快速迭代。

**Q：为什么选择 Schema 级多租户而不是数据库级隔离？**  
A：管理复杂度低、成本适中、性能好、易于扩展。对于初期用户 1000-10000 级别完全足够。

**Q：AI 生成的代码质量能保证吗？**  
A：MVP 目标 ≥85% 准确率。通过 7 层质量检查（澄清对话、单测、静态分析、AI 审查、人工审核、灰度发布、自动回滚）确保。

**Q：怎样快速验证商业模式？**  
A：先从开源社区获得 100+ 用户验证功能，再向其中 10-20% 的高价值用户销售企业版，根据付费意愿调整定价。
