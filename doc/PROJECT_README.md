## 🎯 核心决策已确定

### 商业定位
```
目标市场：中小企业 IT / 大企业业务流程 / 创业公司
市场规模：TAM $500M-2B，用户意愿 62% 立即试用
核心竞争力：AI 驱动 + 完整 BPM + 企业级安全
商业模式：开源社区（免费）+ 企业版（$5-20k/年）
变现路径：订阅 + 专业服务 + 高级功能按量
```

### 技术选型
```
前端：React 18 + TypeScript + Ant Design Pro
后端：Node.js Express + TypeScript
数据库：PostgreSQL + Redis
流程引擎：Temporal（企业级 BPM）
AI 模型：混合（Llama 7B 本地 + GPT-4 云）
部署：Docker + Kubernetes
成本：$36k/年（模型）+ 基础设施
```

### 质量目标
```
MVP 版本：
  语义正确率 ≥85%
  执行正确率 ≥95%
  生成平均时间 <5 分钟

生产版本：
  语义正确率 ≥95%
  执行正确率 ≥99%
  安全合规率 ≥99%
  可用性 ≥99.5%
```

### 产品范围
```
MVP 功能：表单 + CRUD + 权限 + 日志 + Docker 部署
MVP 时间：4 周
验收标准：能用 AI 一句话生成一个可用系统

三条产品线：
  线 A：AI 完全自动化（表单类）→ 目标用户：非技术人员
  线 B：AI 半自动化（工作流）→ 目标用户：业务分析师
  线 C：AI 辅助编码（自定义）→ 目标用户：开发者
```
